## Thèmes personnels (`.vzt`)

Fichier JSON dans le dossier de configuration `vibez/themes`. Couleurs en `#rrggbb` ou `#rrggbbaa`, 8 `track_colors` exactement. `control`, `clip_style` et `lane_style` sont facultatifs. Un champ obligatoire manquant fait ignorer le fichier avec un avertissement.

Champs : `name`, `bg_dark`, `bg_surface`, `bg_elevated`, `bg_hover`, `control`, `text`, `text_dim`, `text_muted`, `accent`, `accent_dim`, `border`, `border_light`, `divider`, `success`, `danger`, `playhead`, `meter_green`, `meter_yellow`, `meter_red`, `display_bg`, `knob_arc`, `knob_body`, `knob_body_engaged`, `knob_track`, `fader_handle`, `track_colors`, `eq_lf`, `eq_lmf`, `eq_hmf`, `eq_hf`, `clip_body`, `clip_border`, `waveform`, `ruler_line`, `grid_bar`, `grid_beat`, `grid_sub`, `piano_white_row`, `piano_black_row`, `piano_octave_line`, `piano_grid`, `piano_white_key`, `piano_black_key`, `piano_key_label`, `clip_style`, `lane_style`.

Styles par défaut :

| Style | Sombre | Clair |
|---|---|---|
| `clip_style.body_opacity` | 0,55 | 0,55 |
| `clip_style.body_toward_lane` | 0,28 | 0,18 |
| `lane_style.band` | 0,015 | 0,015 |
| grille (libellé / mesure / fine) | 0,18 / 0,11 / 0,07 | 0,26 / 0,16 / 0,10 |
| `lane_style.loop_tint` | 0,05 | 0,07 |
